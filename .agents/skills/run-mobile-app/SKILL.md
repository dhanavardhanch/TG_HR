# Run Mobile App Skill

Activate this skill when the user asks to "Run the mobile app", "launch app", or run Flutter on device.

## Instructions
1. Navigate to `E:\TG_HR_Mobile\TG_HR_Mobile_App`.
2. Check connected devices:
   - Run `flutter devices`.
3. Launch the app:
   - Run `flutter run`.
4. Monitor terminal output for camera initialization, face detection pipeline status, and backend sync logs.
