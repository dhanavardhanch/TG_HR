# Cloudflare Tunnel Setup & Mobile App Sync Skill

## Overview
Cloudflare Tunnel (`cloudflared`) connects your local XAMPP backend (`http://127.0.0.1:8000`) directly to Cloudflare's global edge network over a secure outbound HTTPS tunnel without:
- Opening router ports (no port forwarding)
- Needing a static public IP
- Incurring SSL certificate errors on physical Android devices

This gives you a public HTTPS URL (e.g. `https://random-phrase.trycloudflare.com`) that your Flutter app (`TG_HR_Mobile_App`) can connect to from anywhere (Wi-Fi, 4G, 5G).

---

## 1-Click Launching
In `E:\TG_HR_Mobile\TG_Laravel`:
- Double-click **`start_cloudflare_tunnel.bat`** (or run `powershell -ExecutionPolicy Bypass -File .\start_cloudflare_tunnel.ps1`).
- The script automatically checks for `cloudflared.exe` in `TG_Laravel\tools\`. If not found, it downloads the official signed Windows binary from Cloudflare.
- It exposes `http://127.0.0.1:8000` and displays the live HTTPS URL.

---

## Connecting with the Mobile App (`TG_HR_Mobile_App`)
1. Copy the public URL generated by Cloudflare Tunnel (e.g. `https://brave-panda-123.trycloudflare.com`).
2. Open `E:\TG_HR_Mobile\TG_HR_Mobile_App\lib\constants\api_endpoints.dart`.
3. Update `baseUrl`:
   ```dart
   class ApiEndpoints {
     static const String baseUrl = 'https://brave-panda-123.trycloudflare.com/api/v1';
     ...
   }
   ```
4. Build or hot-restart your Flutter app. The mobile app will now communicate directly with your local XAMPP database!

---

## Testing API Connectivity
Once Cloudflare Tunnel is running, verify with any browser or curl:
```bash
curl https://brave-panda-123.trycloudflare.com/api/health
```
Expected response:
```json
{
  "status": "online",
  "app": "Troogood HRMS API",
  "database": "Troogood_HR_APP",
  "timestamp": "2026-10-03T18:30:00Z"
}
```
