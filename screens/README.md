# Wireframes & Screen Mockups Directory
📂 `E:\TG_HR_Mobile\TG_Laravel\screens`

### How to use this folder:
Drop your wireframe screenshots, UI designs, or mockups into this folder!
Supported formats: `.png`, `.jpg`, `.jpeg`, `.webp`, `.pdf`

### Recommended Naming Convention:
- `01_login_auth.png`
- `02_dashboard_overview.png`
- `03_employee_enrollment.png`
- `04_employee_list.png`
- `05_kiosk_live_monitoring.png`
- `06_attendance_reports.png`
- `07_leave_management.png`
- `08_branch_department_setup.png`

---

### What happens when you drop screens here:
1. Simply inform the agent: *"I have placed the screens in the screens folder, build the backend based on them."*
2. The agent will inspect each image, extract the data tables, form fields, actions, and permissions.
3. The agent will create the database tables, API controllers, and web views corresponding to the wireframes.
